# Financial Performance & Profitability Analysis

## Project Overview
An Excel-based data analysis project focused on evaluating financial performance, profitability, and budget achievement through a dashboard.

## Objectives
- Analyze revenue, gross profit, and cost of goods sold.
- Evaluate profitability using key financial metrics.
- Compare actual performance against budget targets.
- Present business insights through data visualization.

## Tools & Technologies
- Microsoft Excel
- Excel Formulas
- PivotTables
- Charts and Dashboard Visualization

## Key Performance Indicators (KPIs)

| KPI | Value |
|---|---:|
| Total Revenue | 317.97M |
| Gross Profit | 169.24M |
| Cost of Goods Sold (COGS) | 148.72M |
| Gross Profit Margin | 53.23% |
| Budget Achievement | 100.07% |
